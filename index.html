Engineering Highlights

  • Redis Cache-First Read Path: Cuts redirect latency by ~3.7x with sub-millisecond in-memory lookups
  • Write-Buffering Layer: Batches click events in Redis with idempotent, crash-safe PostgreSQL flushes every 60s
  • Connection-Pool Optimization: Diagnosed pool exhaustion (240 pool vs 100 limit, 45.6% failure rate); tuned per-replica sizing for 0% failures across 100-300 users
  • High Concurrency: Sustains ~3,000 RPS at 31ms average latency (100 users), gracefully degrading under CPU saturation without crashing
  • Production Deployment: Deployed with 4 replicas behind Nginx with least-connections load balancing and JWT authentication
